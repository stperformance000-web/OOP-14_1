# 🛒 E-commerce Store Core (Ядро интернет-магазина)

ООП-ядро для платформы электронной коммерции. Проект реализует логику работы с сущностями каталога, поддерживает инкапсуляцию, автоматический подсчет позиций, валидацию цен, а также иерархию наследования.

---

## 🛠 Технологический стек
* **Язык разработки:** Python 3.10+
* **Менеджер зависимостей и окружения:** Poetry
* **Тестирование:** Pytest + Pytest-cov (минимальный порог покрытия >75%)
* **Линтинг и стандарты:** Flake8 (PEP 8)

---

## 🆕 Новое в версии 16.1 (Наследование и полиморфизм)
* **Иерархия классов-наследников:** Созданы дочерние классы `Smartphone` (с атрибутами производительности, памяти, модели и цвета) и `LawnGrass` (с атрибутами страны, срока прорастания и цвета).
* **Строгий контроль типов при сложении:** Метод `__add__` переписан с использованием функции `type()`. Запрещено складывать объекты разных классов (например, смартфон и траву). Попытка вызывает `TypeError`.
* **Безопасность категорий:** Метод `add_product()` защищен с помощью `isinstance()`. В каталог можно добавлять только объекты класса `Product` или его наследников. Любые сторонние типы вызывают `TypeError`.

---

## 🚀 Инструкция по запуску

1. **Развернуть окружение:** `poetry install`
2. **Запустить ядро версии 16.1:** `poetry run python 16.1_main.py`
3. **Прогнать юнит-тесты:** `poetry run pytest --cov=src`

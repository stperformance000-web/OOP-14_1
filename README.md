# 🛒 E-commerce Store Core (Ядро интернет-магазина)

ООП-ядро для платформы электронной коммерции. Проект реализует логику работы с сущностями каталога (Товары и Категории), поддерживает автоматический сквозной подсчет уникальных позиций и импорт данных из конфигурационных файлов JSON.

---

## 🛠 Технологический стек
* **Язык разработки:** Python 3.10+
* **Менеджер зависимостей и окружения:** Poetry
* **Тестирование:** Pytest + Pytest-cov (минимальный порог покрытия >75%)
* **Линтинг и стандарты:** Flake8 (PEP 8)

---

## 🚀 Быстрый старт для разработки

Чтобы развернуть проект локально и подготовить окружение, выполните следующие шаги:

1. **Установка зависимостей и создание виртуального окружения:**
   ```bash
   poetry install
   ```

2. **Запуск демонстрационного скрипта (проверка работы ядра):**
   ```bash
   poetry run python 14.1_main.py
   ```

---

## 🧪 Тестирование и проверка качества кода

В проекте настроено автоматическое тестирование основных сущностей и утилит парсинга.

* **Запуск юнит-тестов:**
   ```bash
   poetry run pytest
   ```

* **Запуск тестов с генерацией отчета о покрытии кода (Code Coverage):**
   ```bash
   poetry run pytest --cov=src
   ```

* **Проверка кода линтером на соответствие стандарту PEP 8:**
   ```bash
   poetry run flake8 src tests
   ```

---

## 📂 Структура данных (JSON)
Каталог товаров инициализируется из файла `products.json`. Любые изменения в ассортименте или ценах вносятся напрямую в этот файл перед запуском системы.

# 🛒 E-commerce Store Core (Ядро интернет-магазина)

ООП-ядро для платформы электронной коммерции. Проект реализует логику работы с сущностями каталога (Товары и Категории), поддерживает автоматический сквозной подсчет уникальных позиций, инкапсуляцию данных и безопасное управление ценами.

---

## 🛠 Технологический стек
* **Язык разработки:** Python 3.10+
* **Менеджер зависимостей и окружения:** Poetry
* **Тестирование:** Pytest + Pytest-cov (минимальный порог покрытия >75%)
* **Линтинг и стандарты:** Flake8 (PEP 8)

---

## 🆕 Новое в версии 14.2 (Инкапсуляция)
* **Приватные атрибуты:** Списки товаров и цены скрыты от прямого изменения извне (`__products`, `__price`).
* **Контролируемый доступ (@property):** Добавлены геттеры и сеттеры для безопасного обновления цен с валидацией (запрет цен <= 0).
* **Интерактивная защита:** Реализовано обязательное подтверждение пользователя в консоли при снижении стоимости товара.
* **Умное объединение дубликатов:** Класс-метод `new_product` автоматически складывает остатки при совпадении имён товаров и выбирает наибольшую цену.

---

## 🚀 Быстрый старт для разработки

1. **Установка зависимостей и создание виртуального окружения:**
   ```bash
   poetry install
   ```

2. **Запуск демонстрационного скрипта (проверка работы ядра 14.2):**
   ```bash
   poetry run python 14.2_main.py
   ```

---

## 🧪 Тестирование и проверка качества кода

* **Запуск тестов с генерацией отчета о покрытии кода (Code Coverage):**
   ```bash
   poetry run pytest --cov=src
   ```

* **Проверка кода линтером на соответствие стандарту PEP 8:**
   ```bash
   poetry run flake8 src tests
   ```
